# Swadeshi Khadi Bhandar — website

Catalogue website for **Swadeshi Khadi Bhandar**, a khadi store in Kandivali West, Mumbai, since 1982.

Shop No. 34, Shreeji Darshan Shopping Centre, 100 S.V. Road, S.M. Road, Kandivali (West), Mumbai 400067
Mon–Sat 10:30 am – 1:30 pm and 3:30 – 8:30 pm · Sunday closed · 022 2861 2828

## Open it

Plain HTML, CSS and a little JavaScript — no build step. Open `index.html` in a browser
(be online so the Google Fonts and the Google Map load).

## What's inside

| Path | What it is |
| --- | --- |
| `index.html` | The website: hero, collections, filterable product catalogue, stories, heritage, craft, Google reviews, visit + live map, footer |
| `version-rustic.html`, `version-luxe.html`, `version-premium.html` | Alternative design directions |
| `images/` | Photos, resized for the web (`images/products/` holds the catalogue photos) |
| `logo/` | SK monogram and horizontal logo, red and white, SVG + PNG, plus a square icon |
| `claude-design-source/` | Original Claude Design source files |

## Publish

Any static host works: GitHub Pages (Settings → Pages → deploy from `main`, root folder), Netlify or Vercel.

## Before going live

- Add the Instagram handle in the footer (currently `Instagram [@handle]`).
- Swap AI model photos for real photos of the shop and products when available.
